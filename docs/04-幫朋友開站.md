# 幫朋友開一個他自己的 CHAT

這份是**交接清單**：照順序做完，你朋友就會有一個完全屬於他的家族聊天室。
每一步的詳細說明都在 [02-部署手冊.md](02-部署手冊.md)，這裡只列順序和要填的值。

> 建議你們坐在一起（或開視訊分享螢幕）做，大約 30 分鐘。

---

## 做完之後會是什麼樣子

| | 你的站 | 朋友的站 |
|---|---|---|
| 網址 | `chat.<你的子網域>.workers.dev` | `chat.<他的子網域>.workers.dev` |
| 程式碼放在 | 你的 GitHub | **他的** GitHub（fork 過去的一份） |
| 資料放在 | 你的 Cloudflare | **他的** Cloudflare |
| 管理員 | 你 | **他** |
| 一開始有什麼 | 你家的聊天記錄 | **全新、空的**，你家的資料一筆都不會過去 |

兩個站完全獨立。他怎麼改、怎麼用，都影響不到你；反過來也一樣。

---

## 誰要做什麼

**這幾件事只能朋友本人做，別人（包含你和 AI）都不能代勞：**

- 用**他自己的 Email** 註冊 GitHub 和 Cloudflare（要收驗證信、同意服務條款）
- 建立 Cloudflare 的 API token，貼進**他自己的** GitHub
- 在他的站上註冊第一個帳號（這個帳號會變成管理員）

> 🔒 **請朋友記住一件事：他的 token 和密碼不要傳給任何人，包含你。**
> 那串 token 等於他整個 Cloudflare 帳號的部署鑰匙。整個過程中沒有任何一步需要
> 把它交給別人 —— 他自己複製、自己貼進自己的 GitHub 就好。

## 交接清單（照順序）

要填的值，先抄起來：

```
原始 repo：  https://github.com/Shane360129/CIM
要用的分支：  claude/cloudflare-web-chat-app-vt1qlj
```

| # | 誰 | 做什麼 | 手冊位置 | 時間 |
|---|---|---|---|---|
| 1 | 朋友 | 註冊 Cloudflare，進 Workers & Pages **取子網域名稱**（這就是他網址的一部分，想清楚再填） | 第二節 | 5 分 |
| 2 | 朋友 | 註冊 GitHub | B-1 | 3 分 |
| 3 | 朋友 | Fork 原始 repo，**記得取消勾選「Copy the … branch only」** | B-2 ① | 1 分 |
| 4 | 朋友 | 在他的 fork 啟用 Actions | B-2 ② | 30 秒 |
| 5 | 朋友 | 把他 fork 的預設分支改成 `claude/cloudflare-web-chat-app-vt1qlj` | B-2 ③ | 1 分 |
| 6 | 朋友 | 複製 Cloudflare 的 **Account ID** | B-3 | 1 分 |
| 7 | 朋友 | 建立 API token（範本：**Edit Cloudflare Workers**，建議設到期日） | B-4 | 3 分 |
| 8 | 朋友 | 在他的 GitHub 新增兩個 secret：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID` | B-5 | 3 分 |
| 9 | 朋友 | Actions → 部署到 Cloudflare → Run workflow（確認分支是對的） | B-6、B-7 | 2 分 |
| 10 | 朋友 | ⚠️ **部署一完成就馬上打開網址，註冊自己的帳號** | 第四節 | 1 分 |
| 11 | 朋友 | 設定 → 管理員 → 設邀請碼 → 複製邀請訊息傳給他的家人 | 第五節 | 2 分 |
| 12 | 朋友 | Cloudflare 帳號開啟**兩步驟驗證** | 第八節 | 3 分 |

第 3、5 步是最容易漏的。漏了的話，他部署出去的會是**缺少資安修正的舊版本**
（網站照樣打得開，所以看不出來有問題）。

第 10 步請不要拖：在他註冊之前，任何找到網址的人都能註冊成管理員。

---

## 之後他想更新到你的最新版本

因為他是 fork 的，GitHub 會幫他記得原始 repo 在哪：

1. 打開他的 repo，確認目前在 `claude/cloudflare-web-chat-app-vt1qlj` 分支
2. 按 **Sync fork** → **Update branch**
3. 到 Actions → 部署到 Cloudflare → Run workflow

更新不會動到他的聊天資料。

## 他的站比使用手冊多兩個功能

使用手冊（[03-使用手冊.md](03-使用手冊.md)）寫的是核心功能。他的站另外還有：

- 🍽️ **今天吃什麼** —— 隨機抽吃什麼，也能抽三個丟給大家投票
- 🎮 **小遊戲** —— 圈圈叉叉、五子棋、2048、數獨等十一款

都在聊天室右上角 **☰** 裡，點進去就會用。

## 費用

**兩個帳號都免費，不用綁信用卡，也不會收到帳單。**
Cloudflare 免費方案超過額度時只會讓操作失敗，不會自動扣款；
要付費必須他自己主動升級。詳見部署手冊第九節。
