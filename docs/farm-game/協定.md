# 晴耕谷：雙人同步協定

連線：`wss://網域/farm/ws?conv=對話id`，子協定帶 `farm.v1` 和 `token.登入token`。
Worker（`src/index.js` 的 `farmRoomFetch()`）先請 `ChatServer` 驗證（token 有效、對話是一對一、來的人是成員），
通過才轉給這個對話的 `FarmRoom`。訊息都是 JSON，`t` 是種類。保持連線用純文字 `ping`，伺服器自動回 `pong`（不會叫醒休眠的實例）。

## 原則

- **伺服器說了算**：格子、錢、時間、換日都由 `FarmRoom` 決定。
- **走動例外**：自己的角色在自己畫面先動，伺服器只記位置、轉給對方。
- **動作是「請求」**：伺服器檢查合法才生效，結果廣播給兩個人；不合法回 `no`。兩人搶同一格，先到的成功。
- **斷線重連**：重新連上會再收到一次完整的 `snapshot`，畫面全部照它重來。

## 客戶端 → 伺服器

| `t` | 欄位 | 說明 |
|---|---|---|
| `move` | `x` `y` `dir` `vx` `vy` | 位置（格）、面向（`up/down/left/right`）、速度方向（-1～1）。方向一變（含停下）就送，一直走時約每 0.9 秒補送一次；兩次至少隔 40 毫秒，太快的會被丟掉。位置會被夾在地圖裡 |
| `act` | `id` `kind` `x` `y` | 動作請求。`id` 是客戶端自己編的號碼，回覆會帶回來。`kind` 目前有 `till`（翻土）、`water`（澆水）、`clear`（鏟平） |
| `bubble` | `text` | 頭上的一句話，最多 40 字 |
| `emote` | `e` | 表情，只能是 `balance.json` 的 `emotes` 裡的 |
| `sleep` | `on` | 上床／起床。上床後一走動就算起床 |

## 伺服器 → 客戶端

| `t` | 欄位 | 說明 |
|---|---|---|
| `snapshot` | `you` `partner` `players` `farm` `tiles` `summary` | 完整狀態。`farm`：`day`、`minute`（遊戲分鐘，360 是早上 6 點）、`money`、`minutesPerSecond`、`dayStart`、`dayEnd`。`tiles`：每格 `{x, y, t, w}`（`t` 1 是翻過的土、`w` 1 是今天澆過）。`summary`：你不在時發生的事，沒有就是 null |
| `join` / `leave` | `p` ／ `id` | 對方上線／離線 |
| `move` | `id` `x` `y` `dir` `vx` `vy` | 對方的位置和速度。收到後照速度往前推，畫面平滑地追過去；差超過 4 格直接跳過去 |
| `ok` / `no` | `id`，`no` 另有 `reason` `tile` | 動作的回覆。`reason`：`far` 太遠、`ground` 不是田、`already` 對方先做了、`untilled` 還沒翻土、`out`、`unknown` |
| `tiles` | `by` `kind` `list` | 格子變了（兩個人都會收到，包括做的人自己） |
| `bubble` / `emote` | `id` `text` ／ `id` `e` | |
| `sleep` | `id` `on` | 誰上床了 |
| `time` | `day` `minute` | 每 10 秒一次；中間由客戶端照 `minutesPerSecond` 自己往前推 |
| `newday` | `reason` `farm` `tiles` | 換日。`reason`：`sleep` 大家都睡了、`late` 凌晨 2 點昏倒、`restore` 回復備份 |
| `replaced` | | 同一個帳號在別的分頁打開了，這條連線不要再重連 |

## 時間與換日

- 一天是早上 6 點到凌晨 2 點（1200 個遊戲分鐘），現實約 15 分鐘（`balance.json` 的 `dayMinutesReal`）。
- 時鐘只在至少一個人在線時走；最後一個人離開就停。
- 在線的人都上床才換日；只有一個人在線就是他自己決定。到凌晨 2 點還沒睡會直接換日。
- 換日時先備份當天結束時的狀態，保留最近 7 天。

## HTTP

| 路徑 | 說明 |
|---|---|
| `GET /api/farmroom/backups?conv=` | 列出備份（哪幾天） |
| `POST /api/farmroom/restore?conv=`，內容 `{ "day": N }` | 回復到第 N 天結束時的樣子，在線的人會收到 `newday`（`reason: restore`） |

兩個都要帶 `Authorization: Bearer 登入token`，只有這個對話的兩位成員可以用。目前遊戲畫面裡還沒有回復的按鈕。

## 存檔

`FarmRoom` 自己的 SQLite：`meta`（農場基本資料、時間）、`chunks`（地圖格子，16×16 一塊存成一列）、`players`（位置、上次在線時的天數和錢）、
`events`（誰做了什麼，給離線摘要用，留 30 天）、`backups`（每日備份，留 7 天）。
格子的變更在每個動作處理完時整塊寫回（一個動作改很多格也只寫幾列）；時間每 10 秒寫一次。

# 階段 4 之後的變動（以這一節為準）

階段 2 的 `act`（`till`／`water`／`clear`）改成下面這些。需要回覆的訊息都帶 `id`，伺服器回 `ok` 或 `no`（帶同一個 `id`）。

## 客戶端 → 伺服器

| `t` | 欄位 | 說明 |
|---|---|---|
| `use` | `id` `slot` `x` `y` | 用背包第 `slot` 格的東西對這一格做事。伺服器照順序判斷：那一格有可以清掉的東西（樹、石頭、樹枝、雜草）→ 要拿對的工具；有成熟的作物 → 收成；否則看手上是什麼（鋤頭翻土、澆水壺澆水、種子播種、肥料施肥、十字鎬整平、鐮刀割掉作物） |
| `swap` | `id` `slot` `b` | 背包兩格對調（同一種會疊起來） |
| `ship` | `id` `slot` `n` | 放進出貨箱（要站在出貨箱旁邊） |
| `buy` | `id` `item` `n` | 在種子攤買東西（要站在攤位旁邊、營業時間內） |
| `chest` | `id` `dir` `slot` `n` | 倉庫箱：`in` 放進去、`out` 拿出來（要站在箱子旁邊） |
| `warp` | `id` `i` | 換地圖：`i` 是這張地圖的第幾個出入口（`exits` 排前面，接著是 `doors`），要站在旁邊 |
| `sleep` | `id` `on` | 上床（要站在床邊） |
| `look` | `look` `name` | 外觀和名字（只收 `data/doll/parts.json` 裡有的） |

`move`、`bubble`、`emote` 不變。

## 伺服器 → 客戶端

| `t` | 欄位 | 說明 |
|---|---|---|
| `snapshot` | 多了 `self` `objs`；`you`、`players` 多了 `map` `look` | `self`：自己的背包、體力、技能（只有本人收到）。`objs`：地圖上可以清掉的東西 `{map, x, y, type, hp}`。`farm` 多了 `season` `weather` `ship` `lastShip` `chest` |
| `self` | `inv` `energy` `energyMax` `skills` | 自己的背包、體力、技能變了（只有本人收到） |
| `farm` | `money` `ship` `chest` | 共用的錢、出貨箱、倉庫箱變了（兩個人都收到） |
| `tiles` | `by` `kind` `list` | 格子：`{map, x, y, t, w, f, c}`，`f` 是肥料、`c` 是作物 `{id, s}`（`s` 0～4 是成長階段，-1 是枯了） |
| `objs` | `by` `list` `drops` | 東西被打了一下或清掉了（`type: null` 是不見了） |
| `fx` | `id` `kind` `map` `x` `y` | 誰做了什麼動作（給對方播動畫用） |
| `warp` | `id` `map` `x` `y` | 誰換了地圖 |
| `look` | `id` `look` `name` | 誰換了造型 |
| `newday` | 多了 `self` `you` `players` | 換日。`farm.lastShip` 是剛結算的出貨明細 `{day, total, lines: [{id, q, n, by, sum}]}` |

`no` 的 `reason`：`far` `ground` `locked` `already` `untilled` `tired` `full` `season` `crop` `late` `nothing` `tool:工具名`（要用哪種工具）`money` `closed` `unsellable` `unknown` `slot` `look`。

## 換日時伺服器做的事

1. 備份（農場、格子、東西、兩個人的資料）。
2. 出貨箱結算，錢進共用的錢包。
3. 作物：昨天有澆水的長一天；換季時不是當季的枯掉；今天下雨的話戶外的田自動澆好。
4. 體力：午夜前睡的補滿、午夜後睡的補到 75%、昏倒的只補到 50%、不在線的補滿。昏倒的人被送回農舍。
5. 天氣用農場的種子算（`shared/rules.js` 的 `weatherOf`），同一座農場同一天的天氣固定。
