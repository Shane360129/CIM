# 晴耕谷：平衡

數值都在 `public/games/farm/data/`（`balance.json`、`crops.json`、`items.json`、`animals.json`、`restore.json`…）。
調整之後跑一次模擬看結果：

```bash
node tools/balance-sim.mjs > docs/farm-game/平衡模擬.txt
```

最新一次的完整輸出在 `平衡模擬.txt`。

## 模擬怎麼算的

兩個人、每天都玩、10 年。每天的體力 55% 拿去種田（澆水）、35% 拿去釣魚或採礦（各半），剩下的走路和雜事。
田裡種「這一季每天每格賺最多」的作物；賺到的錢照順序花在：動物 → 工具升級 → 開墾 → 擴建農舍 → 修復設施（修復用東西的賣價估成錢）。
這是很粗的模型，用來抓大方向的問題，不是精算。

## 第一次模擬發現的問題與調整（2026-11-11）

第一次跑出來：所有目標在第 72 天（約 18 小時）就全部做完，10 年存款 288 萬沒地方花。原因是釣魚太賺、各種目標太便宜。調整：

| 項目 | 原本 | 改成 |
|---|---|---|
| 釣魚一次的體力 | 2 | 4 |
| 農舍擴建（2～6 級）的錢 | 1500／4000／9000／20000／50000 | 3000／12000／40000／120000／400000 |
| 工具升級（銅／鐵／金）的錢 | 300／800／2000 | 1000／4000／15000 |
| 開墾南邊的田 | 2500 | 8000 |
| 鴨／乳牛／綿羊 | 500／1200／1500 | 1400／3500／5000（雞維持 300，當作入門） |
| 修復設施的捐獻數量 | — | 10 個以上的 ×3、其餘 ×2 |
| 八個設施全修好的謝禮 | 5000 | 30000 |

## 調整後的結果

- 第 1 年：動物買齊、工具到鐵、修好全部八個設施（模擬裡約第 59 天；實際上要湊齊指定的東西，會比用錢估的慢）。
- 工具到金約第 126 天（第 2 年）；農舍第 5 級約第 179 天、第 6 級約第 397 天（第 4 年，約 99 小時）。
- 主要目標做完大約 100 小時，符合內容量表「主線與小鎮修復約 100～150 小時」。

## 還沒解決的問題

1. **夏、秋、冬沒有作物**。目前只有 16 種春季作物，所以春天的收入是其他季節的四到五倍（春 16 萬、其他各 3 萬多）。要補上夏秋冬的作物資料，這是下一個內容包最該做的。
2. **第 4 年之後錢沒地方花**：存款每年多 25 萬。需要長期的花錢目標（家具與裝潢、建築升級、溫室、島嶼…），見 `長期路線.md`。
3. **草莓太強**：每格每天 23 元，是花椰菜的近兩倍。會再長的作物（草莓、豌豆、蘆筍、蠶豆）整體偏高，之後要把種子價格拉高或再長的間隔拉長。
4. 模擬沒有算進去的：加工品（果醬、起司…）、料理、委託、節慶、成就獎金、技能等級對品質的影響、兩個人體力花在哪裡的差異。
5. 成就「豐收 Ⅴ」（收成 10000 次）照這個節奏約 6 年達成；「生意人 Ⅳ」（出貨 100 萬）約 4 年。等夏秋冬作物補上後要重新看。
