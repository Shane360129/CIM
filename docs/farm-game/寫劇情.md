# 晴耕谷：怎麼寫劇情

晴耕谷是一款在聊天室裡的雙人農場遊戲：兩個好朋友（玩家）一起搬到一座荒廢的農場，種田、養動物、釣魚、挖礦，認識小鎮的 24 位居民，把年久失修的小鎮慢慢修好。
氣氛溫暖、慢慢來、生活感，像台灣的鄉下小鎮。全部用**台灣繁體中文**（台灣的用語和標點：「」、……、！？）。所有名字、地名、劇情都是原創。

## 一段劇情的格式（JSON）

```json
"xiaoman_6": {
  "npc": "xiaoman",
  "hearts": 6,
  "title": "麵包店的夢",
  "steps": [
    { "fade": "下過雨的早晨，餐館還沒開門。" },
    { "say": "xiaoman", "face": "happy", "text": "你來得正好！我做了一個決定。" },
    { "choice": [
      { "text": "什麼決定？", "pts": 40, "goto": "ask" },
      { "text": "先讓我猜猜看", "pts": 60, "goto": "guess" }
    ] },
    { "label": "ask" },
    { "say": "xiaoman", "text": "……" },
    { "goto": "end" },
    { "label": "guess" },
    { "say": "xiaoman", "face": "shy", "text": "……" },
    { "label": "end" },
    { "say": "xiaoman", "text": "……" },
    { "end": true }
  ]
}
```

每一步（steps 裡的一個物件）**只能有一個動作**：

| 動作 | 寫法 | 說明 |
|---|---|---|
| 說話 | `{ "say": "居民id", "face": "happy", "text": "……" }` | face 可以不寫（就是 normal）。可以用的表情：`normal`、`happy`、`sad`、`shy`（臉紅）、`closed`（閉眼）。玩家自己說話用 `"say": "@me"`。 |
| 旁白 | `{ "narrate": "……" }` | 沒有頭像的一句旁白（斜體），描述動作或心裡想的事。 |
| 換場 | `{ "fade": "傍晚的海邊……" }` | 畫面暗下來，中間出現一句話，兩秒後亮回來。適合開場和時間跳過。 |
| 選項 | `{ "choice": [ { "text": "…", "pts": 60, "goto": "標籤" }, … ] }` | 2～3 個選項。pts 是加多少好感（好的回答 50～80，普通 20～40，不好的 0 或 -20）。goto 跳到標籤。可加 `"flag": "旗標名"` 記住玩家選了什麼。可加 `"prompt": "（要說什麼？）"` 換掉預設的「（要怎麼回答？）」。 |
| 標籤 | `{ "label": "名字" }` | 給 goto 跳。 |
| 跳轉 | `{ "goto": "名字" }` | 跳到那個標籤（用來讓分支在結尾會合）。 |
| 冒表情 | `{ "emote": "😊" }` | 玩家頭上冒一個表情。只能用這六個：😊 ❤️ 👍 😴 ❗ 🎵。主線、兩個人的劇情可以加 `"who": "@partner"` 等。 |
| 停一下 | `{ "wait": 1 }` | 停幾秒（最多 3）。 |
| 結束 | `{ "end": true }` | 放在最後。 |

文字長度：
- 一句話 **最多 70 字**，最好 15～40 字。長的就拆成兩句。
- 選項的字 **最多 16 字**。
- 標題 **最多 12 字**。

## 心事件（居民的故事，hearts）

- id 寫成 `居民id_心數`，例如 `ahe_4`。欄位：`npc`、`hearts`、`title`、`steps`。不要寫 when／reward／album。
- 好感到那個心數之後，玩家**跟那位居民說話**時觸發。所以開場要自然：可以用 fade 換到某個時間地點（「傍晚的雜貨店，阿禾在數貨……」），也可以直接從他說話開始。
- 這是**一個玩家**看的（另一個玩家不在場），居民對玩家說「你」。提到農場時可以說「你們的農場」「你們兩個」（農場是兩個人一起經營的）。
- 玩家可能是男生或女生，**不要用他／她來指玩家，也不要假設玩家的性別**。兩個玩家之間是好朋友（也可能是情侶），居民不要亂猜他們的關係。
- 每段 **12～24 步、150～320 字**，至少一個選項，選項會分支、最後會合到同一個結尾。
- 2 心：剛變熟，一件小事讓你看到他的另一面。4 心：願意說出一點煩惱或過去。6 心：說出心裡重要的事、請你幫忙或一起做一件事，關係更深一層（還不是告白，6 心都是友情，**不要寫戀愛**）。
- 要接得上這位居民已經有的劇情和他平常說的話（個性、平常說的話在 `data/npcs/residents.json`，已經有的劇情在 `data/events/hearts.json`）。可以讓其他居民客串（`"say"` 寫別的居民 id），例如春嬸的劇情裡小滿出來講一句。
- 小鎮背景：小鎮有八個年久失修的地方（鐘樓、圖書館與博物館、溫泉澡堂、火車站、港口燈塔、市集廣場的大棚架、山上的神木小祠、學校），玩家們正在一個一個修好。居民的故事可以提到這些，但**不要寫成已經修好了**（玩家可能還沒修）。
- 不要提到遊戲機制的字眼（好感、心數、按鈕、任務）。

## 地點

地圖：`farm` 自家農場、`house` 農舍裡、`road` 往小鎮的路、`lake` 湖邊（有礦坑入口）、`town` 小鎮（雜貨店、餐館、診所、鐵匠鋪、木工屋、噴水池、佈告欄）、
`forest` 森林（有荷花池和木棧道、山上的神木小祠）、`beach` 海邊（燈塔、碼頭、棧道）、`greenhouse` 溫室、`uptown` 鎮北街（圖書館、學校、花店、溫泉澡堂、寵物店、農會、火車站、公車站）。

## 主線（story.json）和兩個人的劇情（duo.json）

跟心事件的差別：

```json
"story_town": {
  "title": "小鎮的老時鐘",
  "npc": "ahe",
  "shared": true,
  "when": { "map": "town", "after": "story_arrive" },
  "reward": { "items": [["dish_veg_soup", 1]], "money": 300, "pts": { "ahe": 30 } },
  "album": "第一次走進小鎮",
  "steps": [ ... ]
}
```

- 沒有 `hearts`。`npc` 是這段的主角（選項的 `pts` 預設加給他；要加給別人就在選項上寫 `"npc": "居民id"`）。
- `when`：什麼時候自己發生（玩家走到那裡、條件都符合就開始，不用跟誰說話）。每一項都可以不寫，寫了就要全部符合：

| 條件 | 寫法 | 意思 |
|---|---|---|
| `map` | `"town"` 或 `["farm", "road"]` | 在哪張地圖 |
| `at` | `[x, y, 半徑]` | 走到某個地方附近（要配 `map`） |
| `day` | `2` | 第幾天以後 |
| `season` | `"summer"` 或陣列 | 季節：spring、summer、autumn、winter |
| `weather` | `"rain"` 或陣列 | 天氣：sun、cloud、rain、storm、wind、snow |
| `hour` | `[18, 26]` | 幾點到幾點（凌晨 1 點寫 25；一天是 6 點到 26 點） |
| `after` | `"story_town"` 或陣列 | 看過哪幾段 |
| `flags`／`notFlags` | `"dream_field"` 或陣列 | 選過（沒選過）哪個選項的旗標 |
| `stats` | `{ "harvest": 20 }` | 農場的統計（收成、出貨、釣魚、翻土 till、節慶 festival……） |
| `restored` | `4` | 小鎮修好幾個地方 |
| `fixed` | `"clocktower"` | 修好了哪個地方（restore.json 的 id） |
| `hearts` | `{ "xiaoman": 4 }` | 跟某位居民幾心 |
| `houseLv` | `2` | 農舍幾級 |
| `together` | `true` | 兩個人都在（同一張地圖、6 格內）：兩邊同時開始 |

- `shared: true`（主線的大事）：另一個玩家剛好在旁邊、也符合條件就一起看；不在就各自看。
- `reward`：`items` 進背包（滿了放倉庫箱）、`money` 進共用的錢包（兩個人只給一次）、`pts` 加好感。
- `album`：演完在紀念冊寫一頁（22 字以內）。
- 兩個玩家說話：`@me` 自己、`@partner` 對方。`together` 的劇情用 `@a`、`@b`：兩邊畫面上是同一個人說同一句（`@a` 是先觸發的人），所以要寫成**不分男女、誰說都合理**的話。
- `together` 的劇情裡，選項是每個人自己選、看不到對方選什麼：**選項的分支裡只能用 `@me`、旁白、居民**，會合之後才再用 `@a`／`@b`。
- 一般的主線章節（不是 `together`）只讓 `@me` 說話（對方不一定在）。提到對方用 `{partner}`（名字），自己是 `{me}`。
- 文字裡的 `{me}`、`{partner}`、`{a}`、`{b}` 會換成名字。

## 放進遊戲

寫好的劇情放進 `public/games/farm/data/events/` 的 `hearts.json`（居民的故事）、`story.json`（主線）、`duo.json`（兩個人的回憶），跑檢查：

```
node scripts/check-farm-events.mjs
```

檢查格式、說話的人、表情、跳轉的標籤、條件、獎勵的物品、字數，還會把每一種選法都走一遍（走得到結尾、最後會合到同一句）。
還沒放進去的草稿可以一起檢查：`node scripts/check-farm-events.mjs heart:草稿.json story:草稿.json duo:草稿.json`。
