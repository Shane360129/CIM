## 階段 1　入口與遊戲骨架（2026-11-10）

做了什麼
- 入口：一對一聊天（不含記事本）的 ☰ 選單，「家族牧場」換成「我們的農場」；群組和記事本不變。
- 面板：同源 iframe 載入 `/games/farm/?conv=對話id`。電腦蓋在聊天區上（右上角可切全螢幕），手機全螢幕。
  關閉方式：右上角 ✕、Esc、手機返回鍵、換到別的聊天室。面板開著時這個對話有新訊息，右上角亮紅點。
- 遊戲骨架 `public/games/farm/`：`core/`（迴圈、畫布、場景、相機、輸入、資源）、`render/`（地面、暫代圖）、
  `net/auth.js`、`ui/hud.js`、`scenes/`（載入 → 標題 → 遊戲）、`data/`（數值、物件、測試地圖）。`systems/` 還是空的。
- 測試地圖：程式畫的草地、小路、田、水；暫代的樹、石頭、草叢、農舍、出貨箱；暫代角色可以走、會被擋住、相機跟隨、依腳的位置排前後。
- 登入身分：選「讀同網域的 localStorage token」，不用父頁 postMessage。理由：遊戲頁自己重新整理也還是登入的，
  也沒有「父頁還沒準備好」的時間差。進遊戲前用 `/api/me`、`/api/conversations` 確認是這個一對一對話的成員。

改到的既有檔案
- `public/app.js`：`chatFeatureItems()`（選單項目）；新增 `openFarmPanel()`、`closeFarmPanel()`、`farmPanelNotify()`；
  `openConv()`、`openConvAt()`、`closeChat()` 各加一行關面板；WebSocket 的 `message` 事件多呼叫 `farmPanelNotify()`。
- `public/style.css`：檔案最後加 `.farm-panel` 等樣式；電腦版的 `.chat` 加 `position: relative`。
- `src/index.js`：`/games/farm/` 的 `X-Frame-Options` 改 `SAMEORIGIN`，其他頁面仍是 `DENY`。
- `public/sw.js`：`/games/farm/` 改成先連網路、連不上才用快取。

怎麼測

  23 項全過（電腦 18 項、手機模擬 5 項）。`npm test` 344 項、`npm run test:farm` 422 項也都過。
- 手動：兩個互為好友的帳號開一對一聊天 → 右上角 ☰ →「我們的農場」→ 點一下開始 → WASD／方向鍵走路、
  數字鍵切快捷列、空白鍵或點地面會標出那一格 → Esc 或 ✕ 關閉，回到聊天。手機用搖桿和「動作」鈕。

## 階段 2　伺服器與雙人同步（2026-11-10）

做了什麼
- `src/farmroom.js`：新的 Durable Object `FarmRoom`，每個一對一對話一個（`idFromName('farm:' + 對話 id)`），用 Hibernation API，自己的 SQLite。
- 驗證放在 Worker：`src/index.js` 的 `farmRoomFetch()` 先請 `ChatServer` 查 token 和成員，通過才轉給 `FarmRoom`，
  並把驗證過的身分寫在 `x-farm-auth` 標頭（瀏覽器自己帶的同名標頭會被丟掉）。`/internal/*` 不對外。
- 同步協定寫在 `協定.md`：快照、走動（位置＋速度）、動作請求與先到先得、泡泡、表情、睡覺、換日、斷線重連。
- 存檔：格子分 16×16 區塊存；每天換日自動備份、留 7 天；`/api/farmroom/backups`、`/api/farmroom/restore` 可以回復。
- 時間：伺服器用 alarm 每 10 秒推進，只有至少一人在線時才走；在線的人都上床才換日，凌晨 2 點強制換日。
- 離線摘要：上線時顯示「你不在時發生的事」（過了幾天、對方做了什麼、錢差多少）。
- 遊戲畫面：看得到對方走動（平滑）、頭上的泡泡和表情（💬／T 鍵、😊）、左上角時鐘、傍晚和晚上天色變化；
  快捷列 1 鋤頭、2 澆水、3 鏟平，在田上按空白鍵或點那一格；對著農舍的門按空白鍵可以睡覺。
- 免費方案的用量上限查過了，寫在 `架構計畫.md` 第 5 節。

改到的既有檔案
- `src/chatserver.js`：`route()` 加兩個內部路徑；新增 `farmRoomAuth()`、`farmRoomSay()`（代發系統訊息，還沒有地方用到）。既有函式沒動。
- `src/index.js`：新增 `farmRoomFetch()`；`fetch()` 加 `/farm/ws`、`/api/farmroom/*` 的路由，`/internal/*` 一律回 404；多 export `FarmRoom`。
- `wrangler.jsonc`：加 `FARM` 綁定和 migration `v2`（只新增 `FarmRoom` 類別，不動 `ChatServer` 的資料）。
- `package.json`：加 `test:farmroom`。

怎麼測

  然後重開 `npm run dev`（不要刪資料）再跑 `npm run test:farmroom -- after-restart`，確認狀態還在。
- 兩個瀏覽器：`node scripts/test-farmgame-sync-e2e.cjs 截圖資料夾`（15 項，要自己裝 Playwright、要乾淨的資料庫）。
- 階段 1 的 23 項、`npm test` 344 項、`npm run test:farm` 422 項、`npm run test:security` 96 項也都過。
- 手動：一般視窗和無痕視窗各登入一個帳號，開同一個一對一聊天的「我們的農場」。
