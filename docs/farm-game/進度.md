### 5b　料理與加工機（完成）

做了什麼
- 製作台（農場上、出貨箱旁邊）：用木材、石頭、纖維、樹枝、樹液做 10 種加工機（果醬機、醃漬桶、釀造桶、乾燥架、熏製爐、榨油機、美乃滋機、起司機、種子機、蜂箱）。
- 加工機拿在手上，對著農場的空地按動作鍵放下去；拿原料對著它按就開始做，做好了頭上會冒出成品，再按一次拿走。空的機器用斧頭或十字鎬可以收回背包。
  每台機器收的原料類別、要多久、成品叫什麼、值多少都在 `data/machines.json`。
- 加工品不用一種一種寫：名字、價錢、圖示是用「機器＋原料」算出來的（例如蕨菜放進乾燥架 → 蕨菜乾）。種子機是把作物變回兩包種子；蜂箱不用放東西，每兩天產一罐蜂蜜。
- 爐灶（農舍裡）：20 道料理（`data/recipes.json`），材料可以指定物品或一個類別（任何蔬菜、任何魚…）。料理等級夠才會煮，煮菜會漲料理經驗。
- 吃料理（背包裡點它再按「吃」）：補體力；有些有一段時間的效果（走路變快、釣魚比較容易、收成好品質機會變高）。
- 一起料理的加成：煮的時候對方也站在旁邊，煮出來的是 ★ 品質（補得比較多、效果比較久）。

怎麼測
- `npm run test:farmroom`（99 項）、`node scripts/test-farmgame-sync-e2e.cjs`（35 項）、`node scripts/test-farmgame-e2e.cjs`（26 項）。

已知問題
- 需要蛋和牛奶的料理、美乃滋機、起司機現在還做不了（動物在 5c）。夏秋冬的作物和採集物還沒有地方取得，所以用到它們的料理也還煮不了。
- 「學食譜」目前只有「料理等級夠了就會」，還沒有電視、居民教、食譜書。
- 料理的效果只在背包面板看得到，畫面上沒有常駐的圖示和剩餘時間。
- 加工品的圖示是通用容器，還沒有依原料換色。
- 加工機只能放在農場；瀏覽器測試只檢查了面板內容，放機器、加工、煮、吃是伺服器測試在驗。

### 5c　畜牧與寵物（完成）

做了什麼
- 農場東南邊有雞舍和畜舍（各住 4 隻）。對著建築按動作鍵：買動物（可以取名字）、餵乾草、開關放牧、領養寵物。
- 四種家畜（`data/animals.json`）：雞（每天一顆蛋）、鴨（兩天一顆鴨蛋）、乳牛（每天牛奶）、綿羊（三天一次羊毛）。
- 每天餵一份乾草（種子攤有賣，背包沒有會從倉庫箱拿）；開了放牧的話，不下雨、不是冬天的日子牠們自己吃草。
- 好感：有吃到、被摸、被刷毛（要買動物刷）會增加，沒吃到會下降；越喜歡你，產品品質越好。
- 動物在自己的圍欄裡走來走去（位置用時間算，兩個人看到的一樣）；走到旁邊按動作鍵：有產品就收，沒有就摸摸牠。
- 很喜歡你又有空位時，每天有小機會生小孩；小孩的毛色和特性多半像爸媽（20 種特性的資料結構先建好），長大前沒有產品。早上的卡片會說誰出生了。
- 寵物：小狗、小貓各可以領養一隻（不用錢、六種毛色隨機），在家門口附近活動，可以摸。
- 新技能「畜牧」。

怎麼測
- `npm run test:farmroom`（109 項）、`node scripts/test-farmgame-sync-e2e.cjs`（38 項）、`node scripts/test-farmgame-e2e.cjs`（26 項）。

已知問題
- 動物的毛色有存，但圖還不會依毛色換色（圖是縮圖，而且生出來不是純白灰）；特性目前只是顯示，沒有實際效果。
- 沒有圍欄的圖（柵欄那張縮圖切不開），動物看起來是在空地上走。
- 雞舍、畜舍一開始就在，還不用蓋；不能升級。寵物不會跟著人走。
- 生小孩、刷毛、餵乾草成功的情況沒有自動測試（餵食只測了「沒有乾草」）。
