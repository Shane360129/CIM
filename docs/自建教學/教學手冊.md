# 自己架一個家族聊天室：完整教學

這份教學帶你**從零開始**，做出一個屬於你自己的家族聊天室網站：
仿 LINE 的介面、手機可以加到主畫面當 App 用、資料存在你自己的帳號裡。

**你不需要會寫程式。** 程式由 AI（Claude Code）寫，你要做的是：
註冊帳號、複製貼上、按按鈕、在手機上試用、告訴 AI 哪裡不對。

搭配文件：**《建置-prompt.md》**（要貼給 AI 的內容）。

## 一、你會做出什麼

一個網址像 `https://chat.你取的名字.workers.dev` 的聊天室：

- 💬 一對一私訊、群組聊天、已讀回條、「正在輸入…」
- 🖼️ 傳照片、語音訊息、貼圖（可以把家人照片做成貼圖）
- 💛 表情回應、回覆引用、投票、公告、搜尋、收回訊息、連結預覽卡片
- 🔔 網頁沒開也收得到通知
- ✅ 全家共用的待辦清單、📅 會自動提醒的行事曆
- 🎨 十種配色、多種字型、深色模式、長輩用的大字體
- 🙈 上班低調模式（分頁標題偽裝成「線上文件」）
- 🔐 只有拿到邀請碼的人能註冊；家人之間看不到彼此，除非你把他們拉進同一個群組

你是**管理員**：決定誰能加入、可以幫忘記密碼的人重設、可以下載備份。

## 二、需要準備什麼

### 三個帳號

| 帳號 | 用途 | 費用 |
|---|---|---|
| **GitHub** | 放程式碼，並且負責把網站部署上線 | 免費 |
| **Cloudflare** | 網站實際運作和存資料的地方 | 免費，不用信用卡 |
| **Claude** | AI 幫你寫程式 | **需要付費方案**（見下方） |

### 關於 Claude 的費用

寫程式的功能（Claude Code）**不包含在免費方案裡**，至少要訂閱 **Pro**（約 US$20/月）。

- 訂閱前請到 <https://claude.com/pricing> 確認你要訂的方案有包含 **Claude Code**。
- **網站做完之後可以取消訂閱，網站照樣運作**，因為網站是跑在 Cloudflare 上，不是跑在 Claude 上。
  以後想加功能再訂一個月就好。

### 時間

| 階段 | 時間 |
|---|---|
| 準備工作（註冊帳號、設定） | 約 40 分鐘，一次做完 |
| 建造（七個階段） | 每個階段約 1–2 小時，**大部分是在等 AI 做事**。建議分幾天做 |

### 其他

- 一支手機（試用、收驗證碼）
- 一台電腦（用瀏覽器就好，**不用安裝任何軟體**）

## 三、先看懂幾個名詞

看不懂也能照做，但懂了會輕鬆很多。

| 名詞 | 白話解釋 |
|---|---|
| **repo**（儲存庫） | GitHub 上放一個專案所有程式碼的地方。像一個雲端資料夾。 |
| **分支（branch）** | 同一份程式碼的不同版本。`main` 是正式版。AI 會在另一個分支上做事，做完再合併回 `main`。 |
| **PR（Pull Request）** | 「我改好了，請把這些改動合併進正式版」的申請單。你按 **Merge** 就是同意。 |
| **部署（deploy）** | 把程式送上 Cloudflare、讓網址能打開。這份教學設定成：**改動合併進 `main` 就自動部署**。 |
| **Actions** | GitHub 的自動化功能。部署就是它在做。 |
| **Token（權杖）** | 「給程式用的密碼」。GitHub 要用它去操作你的 Cloudflare。可以隨時撤銷，而且**只會顯示一次**。 |
| **Secret** | 存在 GitHub 裡、加密保管的值。存進去之後連你自己都看不到內容，只能覆蓋或刪除。 |
| **Worker** | Cloudflare 上跑你程式的單位。你的聊天室就是一個叫 `chat` 的 Worker。 |

## 四、準備工作（約 40 分鐘）

**請照順序做。** 第 4-7 步的三個 Secret 一定要在開始建造之前設好，否則第一次部署會失敗。

建議開一個記事本，把過程中要抄的東西先貼在那裡（做完要刪掉）。

### 4-1. 註冊 GitHub

1. 打開 <https://github.com/signup>
2. 填 Email、密碼、使用者名稱 → 完成驗證 → 去信箱收驗證信。
3. **開啟兩步驟驗證**：右上角頭像 → **Settings** → 左邊 **Password and authentication**
   → **Two-factor authentication** → 照畫面設定（建議用手機的驗證器 App）。

### 4-2. 建立你的專案 repo

1. 登入 GitHub，右上角 **＋** → **New repository**
2. **Repository name**：取一個名字，例如 `family-chat`
3. 選 **Private**（只有你看得到程式碼）
4. ✅ 勾選 **Add a README file**（**一定要勾**，這樣 repo 才會有 `main` 分支）
5. 按 **Create repository**

### 4-3. 註冊 Cloudflare 並取子網域

1. 打開 <https://dash.cloudflare.com/sign-up> → 填 Email、密碼 → 去信箱驗證。
2. 登入後，左邊選單找 **Workers & Pages**，點進去。
3. **第一次進來會請你取一個子網域名稱。**
   這會變成你網址的一部分：填 `wang-family`，網址就是
   `https://chat.wang-family.workers.dev`。
   - 取好之後不太好改，想清楚再填
   - 用英文小寫和連字號，不要太短
4. **開啟兩步驟驗證**：右上角頭像 → **My Profile** → **Authentication**
   → **Two-Factor Authentication**。
   > 這個帳號就是你全家聊天記錄的鑰匙，**這一步請不要跳過**。

### 4-4. 拿 Account ID

1. 在 Cloudflare 的 **Workers & Pages** 頁面
2. 右側找到 **Account ID**，按旁邊的複製鈕
3. 貼到記事本，標註「Account ID」

### 4-5. 建立 API Token

1. Cloudflare 右上角頭像 → **My Profile** → 左邊 **API Tokens**
2. 按 **Create Token**
3. 在範本列表找 **Edit Cloudflare Workers** → 按 **Use template**
4. 往下找 **TTL**（有效期限），建議設成**一年後**。到期再換一個新的就好。
5. 其他設定不用改，滑到最底按 **Continue to summary** → **Create Token**
6. ⚠️ **畫面會顯示一串很長的英數字，它只會出現這一次。**
   馬上複製，貼到記事本，標註「Token」。

### 4-6. 想一組管理員設定碼

這組密碼用來證明「第一個註冊的人是你本人」。
沒有它，任何人都不能在你的網站上註冊成管理員。

- 自己想一組**夠長、不好猜**的，例如四個不相關的英文字：`purple-bridge-lemon-42`
- 貼到記事本，標註「設定碼」
- **只會用一次**（你註冊管理員帳號的那一次），之後就沒有作用了

### 4-7. 把三個值存進 GitHub Secrets

1. 打開你在 4-2 建的 repo → 上方 **Settings**
2. 左邊找 **Secrets and variables** → 點 **Actions**
3. 按 **New repository secret**，新增**三個**：

| Name（要一字不差） | Secret（值） |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 4-5 的 Token |
| `CLOUDFLARE_ACCOUNT_ID` | 4-4 的 Account ID |
| `ADMIN_SETUP_CODE` | 4-6 的設定碼 |

每新增一個都要按 **Add secret**。

> Name 全部大寫、用底線，打錯一個字就會部署失敗。
>
> 存好之後，**把記事本裡的 Token 刪掉**。設定碼先留著，第六章註冊時要用，用完也刪掉。

### 4-8. 註冊 Claude 並訂閱

1. 打開 <https://claude.ai> → 註冊（可以用 Email 或 Google 帳號）
2. 訂閱 **Pro** 或更高的方案（先到 <https://claude.com/pricing> 確認有包含 Claude Code）
3. **開啟兩步驟驗證**（在帳號設定裡）

### 4-9. 讓 Claude 可以存取你的 repo

1. 打開 <https://claude.ai/code>
2. 照畫面指示連結 GitHub（或直接打開 <https://claude.ai/connect-github>）
3. GitHub 會問你要安裝 **Claude GitHub App** 到哪些 repo：
   - 選 **Only select repositories**
   - **只勾 4-2 建的那個 repo**
   - 按 **Install**

> 只給它需要的那一個 repo 就好，你 GitHub 上其他東西它都碰不到。

**準備工作完成！**

## 五、開始建造

### 5-1. 開一個工作階段

1. 打開 <https://claude.ai/code>
2. 選擇你的 repo（4-2 建的那個）
3. 環境用預設的就好，**不用改網路設定**
   （部署是 GitHub 在做，AI 那邊不需要連 Cloudflare）
4. 會出現一個輸入框，這就是你跟 AI 對話的地方

### 5-2. 貼上第一段

打開《建置-prompt.md》：

1. 複製「**給 AI 的共通規則**」灰色框裡的全部內容
2. 複製「**第 1 階段**」灰色框裡的全部內容
3. 兩段一起貼進輸入框，送出

### 5-3. 等 AI 做事

AI 會開始讀、寫、測試程式碼。你會看到它一步一步回報在做什麼。

- **它可能會問你要不要允許某個動作。** 照它的說明判斷；不確定的話，
  問它「這個動作是做什麼的？會不會有風險？」
- **它可能會問你功能上的選擇**（例如某個按鈕要放哪）。用一般的話回答就好。
- **它停下來說用量到了上限：** 這是訂閱方案的使用量限制，等它恢復
  （畫面會告訴你大概多久），之後輸入「請從剛剛中斷的地方繼續」。
- 🚫 **如果它要你貼 Token、Account ID 或設定碼：不要貼。**
  回它：「照共通規則，這些已經放在 GitHub Secrets，部署由 GitHub Actions 執行。」

做完時，它會給你一份「**這階段做完之後，你可以在網站上這樣試**」的清單，
先把它複製下來。

### 5-4. 合併並部署

1. 跟 AI 說：「**幫我開 PR**」
2. 它會給你一個連結，點進去（會到 GitHub）
3. 按綠色的 **Merge pull request** → **Confirm merge**
4. 合併完就會**自動開始部署**

### 5-5. 看部署結果

1. 到你的 repo → 上方 **Actions** 分頁
2. 最上面那一筆就是剛剛的部署
   - 🟡 黃色圓圈：還在跑，等一兩分鐘
   - ✅ 綠色勾勾：成功！
   - ❌ 紅色叉叉：失敗，點進去看錯誤訊息，對照[疑難排解](#十疑難排解)，
     或把錯誤訊息整段複製貼給 AI
3. 你的網址是 `https://chat.你的子網域.workers.dev`
   （也可以在 Cloudflare 的 **Workers & Pages** 裡點 `chat` 看到）

**第 1 階段的第一次部署成功後，請馬上做[第六章](#六第一次上線)。**

### 5-6. 試用

照 AI 給你的試用清單，**在手機和電腦上都試一遍**。

### 5-7. 有問題怎麼跟 AI 說

越具體越好。好的說法：

> 在手機上，進到群組聊天室，按右上角的 ☰，「發起投票」按下去沒有反應。

不好的說法：

> 投票壞了。

說清楚**在哪一頁、按了什麼、預期會怎樣、實際發生什麼**。
它修好之後，一樣「幫我開 PR」→ Merge → 等部署 → 再試一次。

### 5-8. 繼續下一個階段

每一階段都重複 **5-2（只貼那一階段）→ 5-3 → 5-4 → 5-5 → 5-6**。

| 階段 | 做完你會有 |
|---|---|
| 1 | 能註冊、登入、聊天，已讀回條，管理員功能，自動部署 |
| 2 | 照片、語音、貼圖、表情回應、回覆、投票、公告、搜尋、連結預覽 |
| 3 | 通知、離線推播、低調模式、可以加到手機主畫面 |
| 4 | 主題配色、字型、字體大小、深色模式 |
| 5 | 待辦清單、行事曆 |
| 6 | 一份資安檢查報告（AI 會模擬駭客攻擊，找到問題就修好） |
| 7 | 給家人看的《使用手冊》（照實際畫面寫的） |

**小技巧：**

- 同一個對話可以一直做下去。如果對話變得很長、AI 開始搞混，
  就**開一個新的工作階段**，先貼「共通規則」，再說：
  「請先讀 README 和程式碼了解目前進度，然後做第 N 階段。」
- **第 6 階段不要跳過。** 它是唯一會用攻擊者角度檢查整個網站的步驟。

## 六、第一次上線

第 1 階段第一次部署成功之後：

### 6-1. 註冊管理員

1. 打開你的網址
2. 點「**註冊**」
3. 你會看到一個「**管理員設定碼**」欄位（名稱可能略有不同）
4. 填好帳號、暱稱、密碼，以及 4-6 的設定碼 → 送出
5. 進去之後到「**設定**」，看得到「**管理員**」區塊，就代表你是管理員了 👑
6. 把記事本裡的設定碼刪掉

**驗證一下保護有效：** 用另一個瀏覽器（或手機的無痕視窗）打開網址，試著註冊。
應該會因為沒有邀請碼而被擋下來。

> ⚠️ **如果註冊畫面沒有設定碼欄位：** 代表 AI 漏做了。
> **先立刻用一般方式註冊**（搶先成為管理員），再跟 AI 說：
> 「註冊畫面沒有管理員設定碼欄位，請照第 1 階段的要求補上。」

### 6-2. 邀請家人

1. **設定** → **管理員** → 在邀請碼欄位填一組（例如 `wang888`）→ **儲存**
2. 按「**複製邀請訊息**」，它會把網址、步驟和邀請碼組好
3. 用 LINE 或簡訊傳給家人

家人註冊後，系統會自動建立一個跟你的聊天室。

**家人都進來之後**，建議把邀請碼清空再儲存，這樣就關閉註冊了。
已經註冊的人不受影響；之後要加人再臨時開。

### 6-3. 給家人使用手冊

第 7 階段做完後，你的 repo 裡會有 `docs/使用手冊.md`。
在 GitHub 上點開它，把那頁的網址傳給家人。
（repo 是 Private 的話家人打不開，可以把內容複製貼到 LINE 記事本或 Google 文件。）

## 七、日常維護

### 想改東西、加功能

1. 打開 <https://claude.ai/code>，開一個新工作階段，選你的 repo
2. 先貼「共通規則」
3. 用一般的話說你要什麼，例如「我想在聊天室加一個可以釘選照片的相簿」
4. 做完一樣：開 PR → Merge → 自動部署

**更新不會弄丟任何資料。** 訊息、帳號、照片存在 Cloudflare 的資料庫裡，
換程式碼不會動到它們。

### 備份

⚠️ **系統不會自動備份。** 請每一兩個月做一次：

**設定** → **管理員** → **下載聊天備份** → 存到你平常用的雲端硬碟。

重要的照片請另外單獨存一份。

### Token 到期了

到期後部署會失敗（Actions 出現紅色叉叉，訊息跟權限有關）。

1. 照 4-5 建一個新的 Token
2. 到 GitHub repo → **Settings** → **Secrets and variables** → **Actions**
3. 點 `CLOUDFLARE_API_TOKEN` 旁邊的筆 → 貼上新的 → **Update secret**
4. 到 Cloudflare 把舊的 Token 刪掉
5. 到 **Actions** → 選部署那個 workflow → **Run workflow** 重新部署

## 八、安全守則

| ✅ 要做 | ❌ 不要做 |
|---|---|
| GitHub、Cloudflare、Claude 三個帳號都開兩步驟驗證 | 把 Token 或設定碼貼進跟 AI 的對話 |
| Token 只放在 GitHub Secrets | 把 Token 傳給任何人、截圖、存在共用記事本 |
| Token 設到期日，不用了就刪掉 | 把 repo 改成 Public（除非你知道自己在做什麼） |
| Claude GitHub App 只開放給這一個 repo | 跳過第 6 階段的資安檢查 |
| 家人都註冊完就關閉邀請碼 | 長期不備份 |

**你需要知道的事：**

- 聊天內容**沒有端對端加密**。它存在你的 Cloudflare 帳號裡，
  能登入你 Cloudflare 帳號的人就能讀到。所以那個帳號的兩步驟驗證非常重要。
- 管理員可以匯出全部聊天記錄、重設任何人的密碼。管理員帳號的密碼請設強一點。

## 九、費用

| 項目 | 費用 | 說明 |
|---|---|---|
| Cloudflare | **免費** | 不用信用卡，**不會收到帳單**（見下方） |
| GitHub | **免費** | Private repo 每月有 2,000 分鐘的 Actions 額度，一次部署約 1–2 分鐘，用不完 |
| Claude | 約 US$20/月起 | **只有建造期間需要**，做完可以取消，網站照樣運作 |

### Cloudflare 為什麼不會爆

免費方案超過額度時，Cloudflare 的做法是**讓那類操作暫時失敗**，
不是繼續跑然後寄帳單給你。要開始計費，你必須**主動升級**到付費方案。
沒升級就不可能被扣錢。

免費額度每天台灣時間早上 8 點重置：

| 項目 | 每天免費 |
|---|---|
| 請求數 | 100,000 次 |
| 資料寫入 | 100,000 列 |
| 儲存空間 | 5 GB |

一家十個人以內用，一天大概幾千次請求。唯一會慢慢長大的是**儲存空間**，
照片會壓到 450KB 以內，5GB 大約可以放一萬張，幾年內不會是問題。

## 十、疑難排解

### 部署（GitHub Actions 出現紅色叉叉）

| 錯誤訊息裡有 | 原因與解法 |
|---|---|
| 缺少某個 secret | Secret 名稱拼錯或沒設。三個名稱要一字不差，見 [4-7](#4-7-把三個值存進-github-secrets) |
| `workers.dev subdomain` | Cloudflare 還沒取子網域。見 [4-3](#4-3-註冊-cloudflare-並取子網域) 第 3 步，取好後到 Actions 重新 Run workflow |
| `Authentication error`、`Unauthorized`、`10000` | Token 錯了、過期或被刪了。見[Token 到期了](#token-到期了) |
| `Account ID` 相關 | `CLOUDFLARE_ACCOUNT_ID` 貼錯，重新複製一次 |
| 測試失敗（test） | 程式有問題，部署被擋下來了（這是保護機制）。把錯誤訊息整段貼給 AI |
| 看不懂 | 把整段錯誤訊息複製貼給 AI，請它解釋並修正 |

### 網站

| 症狀 | 原因與解法 |
|---|---|
| 註冊時說「管理員設定碼尚未設定」 | `ADMIN_SETUP_CODE` 沒設。到 GitHub Secrets 補上，然後 Actions → Run workflow |
| 註冊時說設定碼不對 | 設定碼有分大小寫。不確定的話到 GitHub Secrets 覆蓋成新的，重新部署後再試 |
| 合併了但網站沒變 | 先到 Actions 確認部署是綠勾。是的話，手機把 App 完全關掉再打開，電腦按 Ctrl+Shift+R（Mac 是 Cmd+Shift+R）強制重新整理 |
| 打開網址是 404 | Cloudflare 子網域沒設定，或還沒部署成功過 |
| 家人說邀請碼不對 | 請用「複製邀請訊息」，不要手打 |
| 連續輸錯被鎖 | 這是防暴力破解的保護，等十幾分鐘就好 |
| iPhone 收不到通知 | 一定要用 **Safari** 加入主畫面，並且**從主畫面的圖示**開啟，才能開離線推播 |

### 跟 AI 合作

| 狀況 | 怎麼辦 |
|---|---|
| AI 說它看不到你的 repo | 到 <https://claude.ai/connect-github> 確認 GitHub 已連結、Claude GitHub App 有裝在這個 repo，然後**開一個新的工作階段**並選這個 repo |
| AI 要你貼 Token 或設定碼 | **不要貼。** 回它：「照共通規則，這些在 GitHub Secrets，由 GitHub Actions 部署。」 |
| AI 說用量到上限 | 等它恢復，再說「請從剛剛中斷的地方繼續」 |
| AI 改壞了原本好的功能 | 具體描述哪個功能壞了，請它修好並補上測試，避免以後再壞 |
| 對話太長、AI 開始搞混 | 開新工作階段，貼共通規則，請它先讀 README 和程式碼再繼續 |
| PR 說有衝突（conflict）不能合併 | 跟 AI 說「PR 有衝突，請幫我處理」 |
