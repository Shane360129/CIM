# 家族牧場的外掛圖包

牧場的圖原本全部是程式畫的。圖包讓你用任何繪圖程式（AI 生圖、Aseprite、手繪）畫的圖蓋過去：
圖包裡有的用圖包的，沒有的照舊用程式畫，所以可以一批一批慢慢換。把 `public/farm-pack/` 整個刪掉，遊戲也照樣能跑。

## 目前圖包裡有什麼

房子（三種等級）、動物小屋、樹（春、夏、秋、冬、櫻花、紅楓、積雪）、雞、鴨、牛、羊、狗、貓。
其他的（地面、作物、人物、小鎮、圖示…）還是程式畫的。

## 加新圖的步驟

1. **畫圖**。規矩只有三條：
   - 純色背景：洋紅 `#FF00FF`（畫紫色的東西改用青色 `#00FFFF`，並在 pack.json 寫 `"bg": "#00ffff"`）
   - 一張圖可以放很多個東西，彼此留空隙，不要有地面、影子、文字
   - 建築畫正面（看得到屋頂），門在正中間；動物畫側面
2. 圖存到 `art-src/farm-pack/`，在 `art-src/farm-pack/pack.json` 的 `sheets` 加一段，
   照「由上到下、由左到右」列出每個東西的名字（名字就是遊戲裡那張圖的名字，見下表）。
3. 跑 `npm run farm:pack`。想先看結果：`npm run farm:pack -- --preview 預覽.png`。
   數量對不上的話它會列出圖上找到的每一塊在哪裡。
4. `npm run test:farm`，再 `npm run dev` 打開牧場看。

## pack.json 的寫法

```json
{ "src": "trees.png", "sprites": [
  { "name": "tree", "w": 48, "h": 56 },
  { "name": "barn", "tiles": [4, 3], "h": 124 }
] }
```

- `tiles`：在地圖上佔幾格（寬、高），不寫就是 1×1。一格是 32×32 像素。
- `w`、`h`：畫布的大小（像素）。比佔的格子大的部分，高度往上長、寬度左右各一半（樹冠可以蓋到旁邊的格子）。
- `flip`：左右翻過來（遊戲裡動物的圖是面向右邊）。
- `colours`：減成幾種顏色（預設 32，建築可以多一點）。
- `skip`：這個東西不要。

`derive` 是從一張圖變出另一張：`recolor` 只改某一段色相（夏天的樹變出春、秋、冬），`bob` 做出動物走路的第二張圖。

## 常用的名字

| 東西 | 名字 |
|---|---|
| 房子（等級 1～3） | `house1` `house2` `house3`（4×3 格） |
| 動物小屋、種子攤位 | `barn`（4×3 格）、`shop`（2×2 格） |
| 樹 | `tree@spring` `tree@summer` `tree@autumn` `tree@winter` `tree@cherry` `tree@maple` `tree@snow` |
| 動物（兩張走路圖） | `chicken_0` `chicken_1`，`duck`、`cow`、`sheep`、`dog`、`cat` 同理 |
| 地面、柵欄、出貨箱… | `grass0@spring`、`path`、`fence_0`～`fence_15`、`bin`…（`public/farm-sprites.js` 的 `sprite()` 收到什麼名字就是什麼） |
| 作物、魚、料理、礦石 | `tomato_3`、`fish_xxx`、`dish_xxx`、`ore_xxx` |

人物（衣服、頭髮顏色每個人不同）還是程式畫的，圖包換不了。
