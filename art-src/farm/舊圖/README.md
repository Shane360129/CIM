# 舊圖

晴耕谷原本用 AI 生成的手繪風美術；2026-11 起改成 LPC（Liberated Pixel Cup）像素風，換掉的舊圖收在這裡，不再給遊戲用。

- `圖集/`：遊戲以前載入的圖集（`b1`、`b5` 是手繪紙娃娃的零件：素體、五官、頭髮、衣服、鞋子、帽子、配件）。
- `第1批/`、`第5批/`：那兩批圖集的生圖原稿和說明（`*.thumb.png` 縮圖進 git；原圖很大，不進 git，只在本機）。
- `紙娃娃/`：手繪紙娃娃的程式和資料（`doll.js`、`parts.json`、對位結果 `fit.json`、自動對位工具 `fit-doll.mjs`、手動對位工具 `doll-align.html`）。

之後地圖、作物、動物、道具也換成 LPC，對應的舊圖會陸續收進來。
